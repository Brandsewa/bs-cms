# Replace the block system with Puck — islands-ready implementation

## Architecture (confirmed with user)

- New shared workspace package `packages/page-builder` (`@bs/page-builder`): Puck config + components (Hero, RichText, Callout, Faq, CtaBanner, FeaturesGrid, ImageBlock, Spacer) styled with branding CSS vars, `sanitizePuckData`, `renderPuckToHtml`, future `defineIsland` helper, styles.css, vitest tests.
- PHP: new guarded `PuckType` field type; pages schema `blocks` → `content` field; migration swaps field row, converts old block data (Hero/RichText/Callout/Faq), strips `blocks` from version snapshots; delete entire block system (registry, controller, routes, CLI sync, definitions); regenerate typed client; update PHP tests + tools/test-release-http.php.
- Admin: `puck-page-editor.tsx` (lazy chunk) embeds `<Puck>` in the existing entry editor card, Puck header hidden, CMS Save/If-Match flow unchanged, MediaPickerModal as image field, token-bridge CSS, delete blocks-field-editor, axe exclusions for canvas.
- Starter (Astro 7.4): add `@astrojs/react` + react; `[slug].astro`/`index.astro` render `<Render>` server-side (zero JS shipped); `preview.astro` becomes a `client:only` React island; `security.csp` + `.htaccess` policy split so future islands pass `script-src 'self'`; `defineIsland` pattern documented for future listing/filter/slider/form components (not built now); starter tests + fixtures.
- Component/prop contract shared by migration and package: `Hero{heading,text,ctaLabel,ctaUrl}`, `RichText{html}`, `Callout{variant,title,content}`, `Faq{items:[{question,answer}]}`, each with Puck `id` prop.

## Execution

Setup (main agent): scaffold workspaces + all package.json dep edits once, single `npm install`. Then: Agent A (PHP backend) and Agent B (package) in parallel → then Agent C (admin) and Agent D (starter) in parallel → main agent runs integration verification (lint, typecheck, tests, size budget, npm audit prod gate), sim E2E (migration, author page in Puck, publish, static rebuild, CSP check), docs updates, and commits.
